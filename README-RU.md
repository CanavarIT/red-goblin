# Гоблин Красный

Говорящий формантный синтезатор речи, который целиком работает в браузере, плюс бесплатная библиотека и HTTP API на том же движке. Без зависимостей и сборки: веб-версии — **одиночные HTML-файлы**, которые генерируют речь с нуля кодом цифровой обработки сигналов.

Голос намеренно роботизированный и хриплый, как у гоблина из старой игры.

[English version: README.md](README.md)

## Структура репозитория

```
.
├── red-goblin-ru.html     Русская речь, русский интерфейс
├── red-goblin-eng.HTML    Английская речь, английский интерфейс
├── api/
│   ├── goblin.js          Библиотека: русский и английский движки (Node.js и браузер)
│   ├── server.js          Бесплатный HTTP API (Node.js, без зависимостей)

```

Папка `api/` не зависит от HTML-файлов. Можно пользоваться любой частью отдельно.

## Веб-версия

Откройте `red-goblin-ru.html` (русская речь) или `red-goblin-eng.HTML` (английская речь) в современном браузере (Chrome, Edge, Firefox, Safari, в том числе мобильном). Введите текст и нажмите **Говорить** (в английской версии — **Speak**).

### Возможности

- Чистый формантный синтез (упрощённая модель Клатта): источник голосовых связок, три настраиваемых формантных резонатора плюс фиксированные верхние форманты и нормированный шумовой резонатор для шипящих и взрывных.
- Встроенное преобразование текста в фонемы, без внешних данных для синтеза.
- Восемь настроек в реальном времени: скорость, высота, интонация, размер глотки, 8-битный хрип, громкость, шипение, сила взрывных.
- Длинные тексты режутся на куски, синтезируются по очереди и сразу проигрываются.
- Вопросительная интонация: `?` в конце поднимает тон.
- Скачивание результата в WAV 16 бит (в ZIP, если площадка ограничивает типы файлов).

### Настройки

| Настройка | Параметр API | Диапазон | По умолчанию | Что делает |
|---|---|---|---|---|
| Скорость | `speed` | 0.6 – 1.6 | 0.8 | Темп речи |
| Высота, Гц | `pitch` | 70 – 220 | 105 | Базовая высота голоса |
| Интонация | `accent` | 0 – 1 | 0.5 | Ударные акценты и плавное падение тона по фразе |
| Размер глотки | `fm` | 0.8 – 1.35 | 1 | Масштабирует все форманты: меньше — глотка больше, больше — меньше |
| Хрип 8-бит | `crush` | 0 – 1 | 0.1 | Снижение разрядности и частоты дискретизации для «хрустящего» звука |
| Громкость | `vol` | 0.8 – 3 | 1.5 | Усиление на выходе (мягкое ограничение) |
| Шипение | `hiss` | 0 – 1.5 | 0.5 | Сила шума в с, ш, щ, ф и подобных звуках |
| Взрыв п/т/к | `burst` | 0 – 1 | 0.6 | Сила «взрыва» в п, т, к |

### Ручное произношение

**Русский.** Поставьте `+` перед ударной гласной: `прив+ет`. Слова без знака берутся из встроенного словаря частых слов, остальные произносятся по правилам.

**Английский.** Пишите фонемы в фигурных скобках в стиле ARPAbet, цифра `1` отмечает ударение:

```
{hh ax l ow1}
```

Гласные: `aa ae ah ao eh er ih iy uh uw ax` и дифтонги `ay ey ow aw oy`.
Согласные: `p b t d k g m n ng l r w y f v th dh s z sh zh hh ch jh`.

Обе версии читают цифры словами и делают паузы на знаках препинания.

## API (`api/`)

### HTTP-сервер

Нужен Node.js 16 или новее. Устанавливать пакеты (`npm install`) не требуется.

```bash
cd api
node server.js            # слушает порт 3000 (меняется переменной PORT)
```

| Запрос | Описание |
|---|---|
| `GET /speak?text=Hello&lang=en` | Возвращает `audio/wav` |
| `POST /speak` с JSON `{"text":"Привет","lang":"ru","pitch":90}` | Возвращает `audio/wav` |
| `GET /health` | `{"ok":true}` |
| `GET /` | Краткое описание API и параметров |

Параметры: `text` (обязательный), `lang` (`en` или `ru`, по умолчанию `en`) и любые из `speed`, `pitch`, `accent`, `fm`, `crush`, `vol`, `hiss`, `burst` из таблицы выше. Значения вне диапазона обрезаются до границ.

Примеры:

```bash
curl -o hello.wav "http://localhost:3000/speak?text=Hello%20goblin&lang=en&pitch=90"

curl -o privet.wav -X POST http://localhost:3000/speak \
  -H "Content-Type: application/json" \
  -d '{"text":"Привет, я гоблин красный","lang":"ru"}'
```

```js
// браузер
const res = await fetch('https://ВАШ-ХОСТ/speak?text=Hello&lang=en');
new Audio(URL.createObjectURL(await res.blob())).play();
```

Ошибки приходят в JSON `{"error": "..."}` с кодами `400` (неверный ввод), `413` (слишком длинный текст), `422` (нечего произносить), `429` (превышен лимит запросов).

Настройки сервера (переменные окружения):

| Переменная | По умолчанию | Значение |
|---|---|---|
| `PORT` | 3000 | Порт |
| `MAX_CHARS` | 500 | Максимальная длина текста в запросе |
| `RATE_LIMIT` | 30 | Запросов с одного IP в минуту |
| `TRUST_PROXY` | выкл. | Поставьте `1` за обратным прокси или CDN, чтобы лимиты считались по реальному IP клиента из `X-Forwarded-For` |

CORS включён для всех источников, успешные ответы кэшируются на час.

### Библиотека

`api/goblin.js` работает в Node.js (CommonJS) и в браузере (глобальный `Goblin`):

```js
const Goblin = require('./goblin.js');

const samples = Goblin.synthesize('Привет, я гоблин красный', { lang: 'ru', pitch: 90 });
// Float32Array, моно, 22050 Гц, значения от -1 до 1

const wav = Goblin.toWav(samples);   // Uint8Array с WAV-файлом 16 бит
require('fs').writeFileSync('goblin.wav', wav);
```

```html
<script src="goblin.js"></script>
<script>
  const s = Goblin.synthesize('Hello', { lang: 'en' });
  const ctx = new AudioContext();
  const buf = ctx.createBuffer(1, s.length, Goblin.sampleRate);
  buf.copyToChannel(s, 0);
  const src = ctx.createBufferSource();
  src.buffer = buf; src.connect(ctx.destination); src.start();
</script>
```

Также экспортируются: `Goblin.sampleRate`, `Goblin.languages`, `Goblin.defaults`, `Goblin.ranges`.

### Бесплатный хостинг

Сервер — обычный процесс Node.js, поэтому он запускается там, где можно выполнить `node server.js`: Render, Fly.io или свой VPS. У бесплатных тарифов свои лимиты, и они со временем меняются, поэтому проверьте актуальные условия хостинга. На бесплатном плане держите `MAX_CHARS` и `RATE_LIMIT` скромными.

## Как это работает

1. **Текст в фонемы.** Словарь частых слов задаёт нестандартное произношение и ударение. Всё остальное идёт по правилам: в русском это редукция гласных, уподобление по звонкости, оглушение на конце и мягкие согласные; в английском — правила чтения букв (немая e, диграфы, окончания `-ed` / `-es`, мягкие c и g, гласные с r).
2. **Фонемы в управляющие сегменты.** Каждая фонема превращается в один или несколько сегментов с целевыми формантами, звонкостью, придыханием, уровнем шума, длительностью и временем перехода. Дифтонги и взрывные состоят из нескольких сегментов.
3. **Синтез.** Сэмпл за сэмплом на 22,05 кГц: импульс голосовых связок, каскад резонаторов и параллельный шум. Затем фильтр низких частот, мягкий компрессор, чтобы тихие согласные не тонули, и необязательное 8-битное огрубление.

## Ограничения

- Это правиловый формантный синтезатор, а не нейросетевой TTS. Редкие слова, имена и иностранные слова могут звучать неточно. Добавьте слово в таблицу словаря (`DICT` для русского, `D` для английского) или используйте ручное произношение.
- Английская орфография нерегулярна, поэтому английский движок сильнее опирается на словарь, чем русский.
- В русском движке латиница читается грубой транслитерацией. Английский движок читает только a–z.

## Настройка под себя

- **Таблицы фонем, словари и правила** лежат в начале каждого движка: в HTML-файлах и в `api/goblin.js` (`makeRu`, `makeEn`).
- **Значения по умолчанию в вебе** — атрибуты `value` у ползунков в HTML. **Значения по умолчанию в API** — объект `RANGES` в `api/goblin.js`.
- В HTML-файлах и в `api/goblin.js` лежат отдельные копии движка. Если меняете правила произношения, обновите обе.

## Заметки о браузере

В веб-версии звук запускается только после действия пользователя (нажатия кнопки), как того требуют браузеры. Используется Web Audio API.
