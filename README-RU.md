# Гоблин Красный

Говорящий формантный синтезатор речи, который целиком работает в браузере. Без зависимостей, без сборки, без сети: каждая версия — **один HTML-файл**, который генерирует речь с нуля кодом цифровой обработки сигналов.

Голос намеренно роботизированный и хриплый, как у гоблина из старой игры.

[English version: README.md](README.md)

## Файлы

| Файл | Язык речи | Язык интерфейса |
|---|---|---|
| `red-goblin-ru.html` | русский | русский |
| `red-goblin-eng.HTML` | английский | английский |

Откройте любой файл в современном браузере (Chrome, Edge, Firefox, Safari, в том числе мобильном). Введите текст и нажмите **Говорить** (в английской версии — **Speak**).

## Возможности

- Чистый формантный синтез (упрощённая модель Клатта): источник голосовых связок, три настраиваемых формантных резонатора плюс фиксированные верхние форманты и нормированный шумовой резонатор для шипящих и взрывных.
- Встроенное преобразование текста в фонемы, без внешних данных для синтеза.
- Восемь настроек в реальном времени: скорость, высота, интонация, размер глотки, 8-битный хрип, громкость, шипение, сила взрывных.
- Длинные тексты режутся на куски, синтезируются по очереди и сразу проигрываются.
- Вопросительная интонация: `?` в конце поднимает тон.
- Скачивание результата в WAV 16 бит (в ZIP, если площадка ограничивает типы файлов).

## Настройки

| Настройка | Что делает |
|---|---|
| Скорость | Темп речи |
| Высота, Гц | Базовая высота голоса |
| Интонация | Ударные акценты и плавное падение тона по фразе |
| Размер глотки | Масштабирует все форманты: меньше — глотка больше, больше — меньше |
| Хрип 8-бит | Снижение разрядности и частоты дискретизации для «хрустящего» звука |
| Громкость | Усиление на выходе (мягкое ограничение) |
| Шипение с/ш/щ | Сила шума в с, ш, щ, ф и подобных звуках |
| Взрыв п/т/к | Сила «взрыва» в п, т, к |

## Ручное произношение

**Русская версия.** Поставьте `+` перед ударной гласной: `прив+ет`. Слова без знака берутся из встроенного словаря частых слов, остальные произносятся по правилам.

**Английская версия.** Пишите фонемы в фигурных скобках в стиле ARPAbet, цифра `1` отмечает ударение:

```
{hh ax l ow1}
```

Гласные: `aa ae ah ao eh er ih iy uh uw ax` и дифтонги `ay ey ow aw oy`.
Согласные: `p b t d k g m n ng l r w y f v th dh s z sh zh hh ch jh`.

Обе версии понимают цифры (читаются словами) и паузы на знаках препинания.

## Как это работает

1. **Текст в фонемы.** Словарь частых слов задаёт нестандартное произношение и ударение. Всё остальное идёт по правилам: в русской версии это редукция гласных, уподобление по звонкости и оглушение на конце, мягкие согласные и т. д.; в английской — правила чтения букв (немая e, диграфы, окончания `-ed` / `-es`, мягкие c и g, гласные с r).
2. **Фонемы в управляющие сегменты.** Каждая фонема превращается в один или несколько сегментов с целевыми формантами, звонкостью, придыханием, уровнем шума, длительностью и временем перехода. Дифтонги и взрывные состоят из нескольких сегментов.
3. **Синтез.** Сэмпл за сэмплом на 22,05 кГц: импульс голосовых связок, каскад резонаторов и параллельный шум. Затем фильтр низких частот, мягкий компрессор, чтобы тихие согласные не тонули, и необязательное 8-битное огрубление.

## Ограничения

- Это правиловый формантный синтезатор, а не нейросетевой TTS. Редкие слова, имена и иностранные слова могут звучать неточно. Добавьте слово в таблицу `DICT` (в английском файле `D`) в исходнике или используйте ручное произношение выше.
- В русской версии латиница читается грубой транслитерацией.
- В английской версии читаются только буквы a–z.

## Настройка под себя

Всё лежит в одном файле. Полезные места:

- **Таблицы фонем** в начале скрипта (частоты формант, длительности, параметры шума).
- **Словарь** (`DICT` в русском файле, `D` в английском).
- **Правила** (`word2ph` в русском, список `R` и `rules()` в английском).
- **Значения по умолчанию** — атрибуты `value` у ползунков в HTML.

## Заметки о браузере

Звук запускается только после действия пользователя (нажатия кнопки), как того требуют браузеры. Используется Web Audio API.
